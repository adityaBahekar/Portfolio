Welcome to the source code of my personal portfolio website — a visually immersive, fully responsive single-page application that reflects my identity as a Full Stack Developer (MERN) and a third‑year CSE student actively seeking internships.

---

## ✨ Features

- **Immersive Boot Sequence** – A terminal‑style loading screen that sets the technical tone.
- **Live Terminal Demo** – Displays an ASCII banner of my name, core competencies with star ratings, and a “ready to contribute” message.
- **Smooth Scroll & Animations** – Scroll‑reveal effects and a subtle parallax glow make the experience engaging.
- **Responsive Design** – Looks great on any device, from mobile to desktop.
- **Interactive Elements** – Hover tilts on skill/project cards, custom cursor glow, and active navigation highlighting.
- **Clear Internship Pitch** – A dedicated “Why me?” section, availability badge, and resume download call‑to‑action.
